# ReniMerge

Visual Components 5.1 Python 3 命令：将选中组件的几何合并到目标组件。

- **作者**：Reni / liren  
- **版权**：Copyright (c) 2026 Reni / liren  
- **版本**：1.0.0  

## 部署

复制本目录到：

`Documents\Visual Components\5.1\My Commands\Python 3\ReniMerge\`

需包含：

- `cmd_ReniMerge.py`
- `PyResource.English.xaml`
- `PyResource.Chinese.xaml`
- `PyResource.TraditionalChinese.xaml`

重启 Visual Components 后，在 **Home → Python3 → Reni 合并**，或 Configure 模式三维视图右键菜单中使用。
